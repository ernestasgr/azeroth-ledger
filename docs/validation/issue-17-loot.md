# Personal loot reconciliation

Issue: [Count personal loot once in the Collection](https://github.com/ernestasgr/azeroth-ledger/issues/17).

The adapter recognizes only localized `LOOT_ITEM_SELF` and `LOOT_ITEM_SELF_MULTIPLE` messages. It requires an item link in a loot window and a complete bag baseline. A receipt and a positive bag quantity change for the same item variant must both exist before units are confirmed. Confirmed units are capped by the bag increase and by the loot-slot quantity when the client supplies one. Duplicate messages and repeated bag scans cannot add units above those caps. Pending sessions and awarded counts are saved with the Collection, so a reload does not restart the count. A session accepts late receipts for 120 seconds after the first `LOOT_CLOSED`; repeated close events do not extend it. Opening another window retains the earlier session's measured bag increase for delayed receipts.

The location is captured from `GetRealZoneText()` when loot opens. A source is recorded only when `GetLootSourceInfo(slot)` identifies one source for that exact item slot. A Creature or Vehicle GUID gives a mob source, and a GameObject GUID gives a container source. A readable mob name is used only when the current target's GUID matches the slot's source GUID. Ambiguous or unavailable source evidence stays Unknown. The adapter does not infer a boss from an elite classification or a nearby target.

The available [build 70009, enUS traces](forever-client.md) support the x2 receipt and bag delta, a receipt after two close events, and a single Creature GUID attached to a loot slot. The earlier pair of identical messages lacks a reliable starting bag count; the +1 duplicate case is a replay test, not a live observation. Headless replay verifies persistence and totals but does not verify the live client event timing.

In-client paths still pending: run `AzerothLedgerCollection` on the installed Forever beta after reload; capture a controlled duplicate-message case with before/after bag snapshots; loot a container, boss, and multi-source area loot; verify another locale; and record build, locale, WoWUnit result, and Lua errors. The current adapter intentionally leaves source Unknown for ambiguous slots and does not classify bosses without item-specific proof.
