# Azeroth Ledger

A planned World of Warcraft: Forever addon for tracking items across your characters. Its Collection shows items you have seen; its Journal shows recent loot, purchases, transfers, and other item activity.

The [completed plan](https://github.com/ernestasgr/azeroth-ledger/issues/1) links the decisions and staged build order. There is no installable release yet.

The addon will use native Forever styling, in-game settings, modular Lua, static checks where practical, and WoWUnit tests.

See [CONTEXT.md](CONTEXT.md) for the plain-language glossary. Client compatibility and saved data must be checked on the intended Forever release build.
